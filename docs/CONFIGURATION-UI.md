# 单文件配置与设置界面

完整项目介绍、架构、启动流程与配置示例见根目录 [README](../README.md)。本文说明表单行为和本地数据处理。

## 使用入口

Start-ClaudePreflight.cmd → “个人配置” → 填写 / 选择 → 保存 → 自动检查。它是当前唯一日常入口。必要配置的未保存修改会禁用启动；仅 DNS 草稿变化不影响启动，保存前使用原配置。字段格式不完整时不能保存。

唯一持久化个人参数的位置是 windows/local/settings.json，首次保存才创建，已被 Git 忽略。公开 settings.example.json 是空模板，tests/public-fixture.json 是虚构数据，均无须填写个人信息。

## 表单与字段

| 界面 | 配置字段 | 约束 |
|---|---|---|
| 本机 HTTP 代理 | proxyUrl | 预填 http://127.0.0.1:，必须补全端口 1–65535；不接受系统默认 80 的隐式推断 |
| 固定出口 IPv4 | expectedEgressIP | 完整单一 IPv4，不支持网段和通配符 |
| 出口国家 / 地区 | requiredCountry | 两字母代码，与时区独立 |
| v2rayN 目录 | proxyRoot | 包含 guiConfigs 的本地绝对目录 |
| TUN 名称 | existingTunName | 精确网卡名，不支持通配符 |
| Windows 时区 | expectedTimeZone | 识别 Windows 系统目录中的时区 ID |
| 区域格式 / 启动语言 | expectedCulture | 一个字段同时派生启动语言 |
| DNS 检测基线 | allowedDnsResolverIPs | 有效检测后自动生成草稿，核对并保存后采用；最多 32 个精确 IPv4 / IPv6 |
| 无须手填 | ownerSid | 保存时记录账号标识，管理员应用要求同一账号 |

应用名、检查超时、保护模式属于公共实现参数。当前路径由官方安装与签名动态发现，启动语言从 expectedCulture 派生，不持久化第二份 clientLanguage。

## 地区显示规则

| 状态 | 范围 | 行为 |
|---|---|---|
| 推荐 | 新加坡、台北、美国 | 显示“推荐” |
| 黄色不推荐 | 中国大陆 | 提示但可选择 |
| 正常显示 | 其他国家 / 时区 | 显示 Windows 原名称，不附加推荐、警告或禁止标记 |

美国按主要 Windows 时区条目展示。多个地区可能共用 Windows 时区 ID，这些标签是项目预设，不是物理位置检测。

新加坡语言选项为 en-SG / zh-SG，台北为 zh-TW，美国为 en-US，大陆为 zh-CN。其余时区提供系统识别的具体区域格式，不增加地区语言配对限制。

所有时区仍检查实际 Windows 设置是否与保存项一致。时区可与出口国家不同，不要求改 Windows 显示语言，不自动改时区或时钟。检查失败或无法确认时显示红色“× 拒绝连接”，创建 Claude 进程前再次复核。

“读取系统地区”可以读取普通地区及其语言。两个设置按钮打开 Windows 时区与区域格式页面，由用户调整后重新检查。语言核对针对将传入的 --lang 参数，不读取 Claude 内部网页语言状态。

## 本地存储

个人参数只写唯一配置文件，保存不生成敏感临时文件、自动备份或额外缓存。写入中断或配置损坏时拒绝启动，需要重新保存。JSON 为本地明文。

当前程序路径与发现指纹留在内存中；status.json / network-test.json 保存状态、计数、公开版本及布尔结果。检查页展示前对地址、路径和账号标识脱敏。Windows 防火墙本身存储程序路径，Windows、代理及 Claude 自行管理其数据。

## 发布副本

双击 Export-PublicPreview.cmd，或执行 tools/Export-PublicPreview.ps1 -OutputPath 指定一个尚不存在的 ZIP。打包排除本地配置、运行数据、日志、备份、账号与程序副本；检查其他文本中重复出现的当前出口、目录和 SID，以及疑似 Anthropic API 密钥；生成相对路径 SHA-256 清单。

图片和自行增加的资料仍需人工审阅；导出不会上传 GitHub。

## 实现位置

| 文件 | 职责 |
|---|---|
| Configuration.ps1 | 唯一配置路径、字段校验、读写、派生语言与脱敏 |
| LocalePolicy.ps1 | 地区标记、系统语言目录、预设配对及实际设置核对 |
| ClaudeLocalUI.ps1 | WPF 表单、未保存状态、异步检查与按钮 |
| ClaudeLocalCore.ps1 | 检查 / 启动 / 修复编排与启动前复核 |
| windows/direct | 精确规则、签名发现、升级适配与网络对照 |
| tools / tests | 公开打包与独立虚构测试 |

历史严格模式草稿入口已禁用。当前默认使用 Windows DirectBlock 流程，见 RELEASE-v1.md；旧平台实现及其参考资料已从发布目录删除。
DNS / WebRTC 仅为黄色提醒；未知、超时和未填基线都不阻止启动。首次设置及诊断范围见 [LEAK-CHECKS](LEAK-CHECKS.md)。观测不会自动写入允许列表。

“IP 质量”输入任意公网 IP 或报告链接，可测试机房 IP，不改启动白名单。自动查询 IPQuery，明确风险分越低越好，并显示独立机房提示；IPinfo.CV、Net.Coffee、IPRisk 与 Scamalytics 只做人工网页入口，Scamalytics 附已保存的固定 IP。详见 [IP-QUALITY-DECISION](IP-QUALITY-DECISION.md)。

代理端口帮助写明 v2rayN 的“参数设置 → Core：基础设置 → 本地混合监听端口”。DNS 基线首次自动填入，或显式点击“填入本次 DNS 地址”更新；不授予 DNS 服务器权限、不更改系统 DNS，也不后台保存。HTTP 固定出口不匹配时仍能自动填入有效 DNS 草稿，并保留该提醒；基线保存不放宽固定出口要求。已保存的基线不因后台检测变化自动扩大。

DNS / WebRTC 统一为一个检测入口，只要求已保存本机代理正确、端口可用，不再依赖 TUN 或固定出口前置条件；诊断结果仅作黄色提醒；能否启动由独立的 10 项必要检查决定。时间显示本机时间及偏移，等待期间显示秒数。

窗口默认最大化；保存按钮最小 220×64，字号 17。时区固定说明只写“推荐新加坡、台北、美国”，大陆条目的黄色不推荐保留。IP 质量页右侧四站统一为 2×2 方框，整张卡可点击，旧版顶部三个单独按钮已移入卡片。

v7 后台检测分别返回：最长约 30 秒，界面可继续操作，不等待 DNS / WebRTC 才显示启动结论。必要字段变更取消旧探针并清空旧结果；达到总时限异步取消，不同步卡住窗口。
