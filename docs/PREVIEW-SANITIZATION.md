# 本机配置与公开打包

当前发布包只包含 Windows 实现、开发测试、导出工具和现行技术说明，没有附带其他平台实现、账号快照或未使用图标。单独的根目录 README 暂缓编写。

个人参数只保存在 windows/local/settings.json。公开导出器排除该文件、运行 JSON、日志、备份、程序副本、账号目录和 Git 元数据；导出时检查当前出口、目录、SID 与 DNS 比较值是否散落到其他文本，并生成 SHA256SUMS.txt。

Windows 防火墙自身仍保存程序路径；规则管理可生成状态 JSON 及系统 curl 的专用测试副本。独立 Edge 在 Temp 建立自有资料目录，正常结束清理，强杀或断电可能残留。这些运行产物不在公开 ZIP 中。“单文件个人配置”不等于运行过程中永远只写一个文件。

观测地址和评分结果只在内存中展示，不生成地址清单。tests/public-fixture.json 使用虚构地址与目录，不是可用于联网的作者配置。工具不读取或保存 Claude 登录凭据。

当前完整性以 ZIP 内 SHA256SUMS.txt 为准；已经删除的早期来源 CSV 和行数统计不再作为发布文件。源代码目录中的私人配置为明文文件，不能连同项目提交或公开分享。具体检测和验证边界见 RELEASE-v1.md、LEAK-CHECKS.md 和 VALIDATION.md。
